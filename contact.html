Bugs and feedback go to the project’s public GitHub repository, next to the code.

Report a bug

Open an issue with the shortest set of steps that makes the problem happen again. It helps to say:

  • which browser and device you used;
  • whether it happened during deployment or the battle;
  • which regiments and terrain were involved;
  • what you expected, and what happened instead.
Open an issue

Gameplay feedback

The most useful feedback describes one moment on the field: a charge that did too little, a retreat that got stuck, archers that picked the wrong target, a route that went the long way round. A specific situation can be tested; a general impression is much harder to act on.
