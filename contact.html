Feedback, bugs and project contact

COFFEE BATTLES is developed in the open. The most useful contact channel is the public GitHub repository, where bugs and reproducible gameplay issues can be tracked alongside the code.

Report a bug

If something breaks during a battle, open a GitHub issue and include the shortest sequence of steps that reproduces the problem. Useful details include the browser, whether the issue happened during deployment or live combat, the unit type involved, the terrain nearby and what you expected to happen instead.

Open a GitHub issue

Gameplay feedback

Feedback is especially useful when it identifies a concrete battlefield behaviour: a charge that feels too weak, a retreat that gets stuck, an archer that chooses the wrong action, an obstacle that produces a bad route, or a formation change that creates an unexpected result. Short observations tied to a specific situation are easier to test than broad balance requests.

Project repository

The current source and development history are available at github.com/erykwest/COFFEE_BATTLES.
